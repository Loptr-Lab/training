Training homeCourse overview

Learn to use AI deliberately

Understand models and context, write effective prompts, test outputs, choose tools, and learn how AI-powered applications work. Provider-neutral concepts remain useful as products change.

No paid subscription, API key, or coding is required for conceptual lessons. Resource links are starting points; this draft has not live-verified all links. Check official documentation and dates for changing features, prices, models, and terms.

Learning outcomes

  • Explain models, tokens, context, inference, and multimodal input.
  • Write prompts with clear goals, context, constraints, and output requirements.
  • Ground outputs and label unknowns.
  • Choose models/platforms using evidence.
  • Test outputs and document failures.
  • Understand APIs, tool calling, retrieval, workflows, and monitoring.
  • Compare image, video, and audio generation.
