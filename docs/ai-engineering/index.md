# AI Engineering: Prompting, Context & Reliable Outputs
**Beginner–intermediate · Self-paced · No coding prerequisite**

Learn to use AI deliberately, evaluate outputs, choose tools, and understand AI-powered applications. Provider-neutral concepts remain useful as products change.

## Outcomes
- Explain models, tokens, context, inference, and multimodal input.
- Write prompts with clear goals, context, constraints, and output requirements.
- Ground outputs and label unknowns.
- Choose models/platforms using evidence.
- Test outputs and document failures.
- Understand APIs, tool calling, retrieval, workflows, and monitoring.
- Compare image/video/audio generation.
