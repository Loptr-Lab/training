# Participant and Agency Review Packet

This branch contains draft materials for participant-assisted agency review. It does not indicate approval.

A participant may give these materials to a counselor or authorized agency reviewer. Only an official acting within documented authority can issue an agency determination, authorization, contract, or vendor approval.

Do not add private participant records to this branch.

1. [Program Summary](./PROGRAM_SUMMARY.md)
2. [Counselor and Agency Questions](./COUNSELOR_AND_AGENCY_QUESTIONS.md)
3. [Individual Authorization Checklist](./INDIVIDUAL_AUTHORIZATION_CHECKLIST.md)
4. [Agency Review Record](./AGENCY_REVIEW_RECORD.md)

Use the current-status and routing documents on `main` as the public source of truth.
