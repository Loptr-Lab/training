# Loptr Lab Accessible Technology Planning

An accessibility-first guide for turning work and creative goals into a technology, training, funding-research, and documentation plan.

## Start here

The [guide homepage](./docs/index.html) is the canonical orientation page. It asks what you need to do next and routes you through one user journey.

| Go to | Use it to |
| --- | --- |
| [Career tracks](./docs/tracks/index.md) | Start with the work you want to do. |
| [Accessibility](./docs/accessibility/index.md) | Describe functional barriers without disclosing unnecessary medical information. |
| [Technology planning](./docs/technology-planning/index.md) | Translate tasks and barriers into minimum, preferred, and alternative configurations. |
| [Funding research](./docs/funding/README.md) | Research programs by jurisdiction and verify current rules. |
| [MCP prompt library](./docs/prompts/README.md) | Use AI research while preserving human judgment and source verification. |
| [Preparation templates](./docs/templates/README.md) | Prepare a needs statement, quotes, questions, and an approval packet. |
| [Worked example](./docs/case-study/README.md) | Follow an anonymized retraining plan from goal through lessons learned. |
| [Legacy curriculum reference](./LEGACY_TRAINING_MANUAL.md) | Consult preserved predecessor material from the earlier README. |

## Scope and privacy

This repository provides educational information and preparation tools. It does not determine eligibility, guarantee funding, or replace advice from a qualified professional. Program rules, prices, and eligibility can change; verify current information with the responsible decision-maker.

Share functional needs and vocational tasks—not passwords, credentials, government identifiers, case numbers, medical records, benefit letters, or confidential documents.

See [contributor safety and governance](./CONTRIBUTOR_SAFETY_AND_GOVERNANCE.md) before contributing.
