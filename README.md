## About This Exercise

This is a standalone coding exercise used by Loptr Lab for candidate evaluation
and VRS-supported training. It's a proxy for real engineering work on
**Veiled Dominion**, an open-source 4-player strategy game engine — see
[github.com/Loptr-Lab/veiled-dominion-engine](https://github.com/Loptr-Lab/veiled-dominion-engine)
for the full project. This exercise does not require or use that repo's C#/.NET
codebase; it's fully self-contained in TypeScript.
